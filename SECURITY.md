# Security Policy

## Scope
This is an early-stage prototype. Security reports are welcome for the Mini App, bot starter and future protocol components as they are added.

## Reporting
Do not disclose exploitable vulnerabilities in public issues. Use GitHub private vulnerability reporting if enabled. If unavailable, contact the repository maintainer through a verified private channel on the GitHub profile.

Include the affected component and version, impact and realistic scenario, reproducible steps or a minimal proof of concept, and a suggested mitigation if known.

Do not access, modify or retain other users' data. Do not test systems or wallets you do not own or have explicit permission to assess.

Please allow time for investigation and remediation before public disclosure. Do not include secrets or personal data in reports.
